一、摘要

《人和医院档案馆》（以下简称"本游戏"）的核心玩法完全离线，无账号、无内购。自 v2.1.0 起，本游戏接入 TapADN 广告 SDK，用于展示少量可选广告（激励视频与插屏），因此新增联网权限；广告均为可选、可跳过，不影响结局与结局图鉴。

若你在首次启动的隐私同意弹窗中选择不同意，我们不会初始化广告 SDK、不会展示广告，也不会进行广告相关的网络请求；游戏的检索、档案、层级解锁、结局与图鉴仍可正常游玩（仅"看广告获得线索"功能不可用）。

二、我们收集哪些信息

2.1 游戏本体

游戏本体不收集任何个人信息：不需要账号，不收集姓名、手机号、身份证号、邮箱、地址等身份信息；不读取位置、通讯录、短信、通话记录、相册、文件、麦克风、摄像头、剪贴板或传感器数据。游玩进度与设置仅保存在你的设备本地（见第六条）。

2.2 TapADN 广告 SDK 收集的信息

只有在你同意隐私政策并实际触发广告请求时，TapADN 广告 SDK 才会收集下列信息，用于广告展示、频次控制、反作弊、效果归因与结算：

  1. 设备标识符：OAID（匿名设备标识符）；在部分系统版本上可能使用 Android ID 等替代标识；
  2. 设备信息：设备型号、制造商、操作系统版本、屏幕分辨率与像素密度、语言与国家/地区、应用包名与版本；
  3. 网络信息：网络类型与连接状态、IP 地址、运营商信息（用于广告请求与区域合规）；
  4. 广告交互信息：广告请求、展示、点击、关闭、完整观看等事件记录；
  5. 运行与诊断信息：SDK 运行日志、错误与性能诊断信息（用于保障广告服务稳定）。

上述信息不用于识别你的真实身份，我们也不会将其与你的姓名、手机号等身份信息关联。

2.3 我们不会收集的信息

本游戏不收集位置信息、通讯录、短信、通话记录、相册、文件、麦克风、摄像头、剪贴板、传感器等任何设备数据；不收集你的账号密码或支付信息（本游戏无账号、无内购）。

三、Android 权限说明

本游戏安装包声明以下 Android 权限：

  • 网络权限：INTERNET（访问网络）与 ACCESS_NETWORK_STATE（读取网络状态）。仅用于 TapADN 广告请求、广告素材加载与网络状态判断；游戏核心玩法不依赖网络，断网或飞行模式下仍可正常游玩（广告不可用）。
  • 本游戏不申请以下权限：存储（读写外部存储）、定位、相机、麦克风、通讯录、电话、短信、日历、身体传感器、后台弹窗、安装未知应用（REQUEST_INSTALL_PACKAGES）、查询已安装应用（QUERY_ALL_PACKAGES）等。

你在手机"应用信息 - 权限"中看到的权限列表仅有上述网络相关权限，属于正常现象。

四、本地存储说明

本游戏使用 Android WebView 的本地缓存（localStorage）保存游玩数据：已解锁档案与隐藏物证、当前封存层级与已解锁结局、环境音/惊吓强度设置、检索错误次数等统计。上述数据仅存放于本机应用私有目录，不包含个人信息，不会上传。

TapADN 广告 SDK 可能在本机缓存广告素材、广告配置或频次控制信息，用于减少重复请求与提升加载速度；相关缓存的清理方式与 SDK 数据权利见第六、八条。

你可以通过游戏内"重置"、系统"清除应用数据"或卸载本游戏清除本地数据。

五、第三方 SDK 与共享

本游戏接入的第三方 SDK 如下：

  • SDK 名称：TapADN 广告 SDK（Dirichlet Ad，SDK 版本 5.3.x）
  • 开发方/运营方：上海艾得蒽数字科技有限公司
  • 收集信息：见第二条 2.2 款
  • 使用目的：广告请求与展示、频次控制、反作弊、广告效果归因与结算、保障广告服务稳定
  • 共享对象：为实现广告竞价与投放，TapADN 可能将必要的设备标识符、广告请求与交互信息共享给穿山甲、优量汇等广告联盟/广告主；共享以广告投放与结算所必需为限
  • 隐私政策：TapADN/Dirichlet 平台 https://ssp.dirichlet.cn/；穿山甲 https://www.csjplatform.com/；优量汇 https://e.qq.com/（以各平台最新隐私政策为准）

除上述广告 SDK 外，本游戏未接入统计、崩溃上报、推送、登录、支付、社交分享等其他第三方 SDK。

你在 TapTap 平台内浏览、预约、下载、评论本游戏时，TapTap 客户端与网站会按照 TapTap 自身的《隐私政策》处理相关平台数据；该等处理由 TapTap 负责，与本游戏无关。

六、个性化广告与关闭方式

  1. 广告可选择性：激励视频仅在玩家主动点击"看广告获得线索"时播放；插屏仅在层级解锁等场景、且距上次插屏不少于 120 秒时展示；广告均可跳过或关闭，广告失败/无广告时不阻断游戏。
  2. 关闭个性化推荐（任选其一）：可在游戏内"设置 → 广告与隐私"开关关闭（如版本提供）；或在 Android「设置 → 隐私 → 广告」中删除/重置广告 ID、关闭"个性化广告"；也可通过本政策末尾的联系邮箱提出关闭申请，我们将协调 SDK 方处理。
  3. 关闭个性化推荐后，你仍可能看到非个性化广告（广告数量可能不变），这不影响游戏本体与结局。

七、未成年人保护与适龄提示

  1. 本游戏为恐怖题材虚构作品，含恐怖氛围、惊吓音效与闪烁画面，并涉及火灾、死亡与医疗记录的虚构描写，建议 16 岁以上玩家体验；启动页与游戏内提供内容提示、"纯属虚构"声明与温和模式。
  2. 本游戏无内购、无付费点、无诱导消费；广告可跳过且不影响结局与图鉴。未成年人体验时，建议在监护人知情并同意的前提下进行；如监护人要求关闭广告或个性化推荐，可通过本政策末尾的联系方式与我们联系。
  3. 本游戏不收集你的姓名、联系方式等身份信息；广告 SDK 的设备信息处理见第二、五条。

八、数据安全

  1. 游戏本体数据仅保存在本机应用沙盒内；卸载应用即清除。
  2. 广告 SDK 的网络传输由其自身实现（通常使用 HTTPS/加密传输）；我们无法访问 SDK 与广告联盟之间的原始数据。
  3. 由于本游戏无自建服务端，我们不存储你的个人信息。

九、你的权利

  1. 你可以通过游戏内"重置"或卸载应用清除本地游玩数据。
  2. 关于广告 SDK 处理的设备信息，你可以通过系统广告设置关闭个性化推荐，或通过本政策末尾的联系方式提出查询、删除、撤回同意等请求；我们将协调 SDK 开发方/联盟方在 15 个工作日内答复处理。
  3. 若你不同意本政策或希望撤回同意，可停止使用并卸载本游戏，或在游戏设置中关闭广告相关功能（如版本提供）。

十、本政策的更新

  1. 若本游戏功能或第三方 SDK 发生变化（如新增或更换广告 SDK），我们会在功能上线前更新本政策，并在游戏内与 TapTap 商店页面以显著方式提示。
  2. 本政策更新后将在本页面发布最新版本并更新"更新日期"；重大变更会单独提示。
  3. 若你不同意更新后的政策，可停止使用并卸载本游戏。
