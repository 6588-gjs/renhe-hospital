# 人和医院在线档案馆

依据《废弃医院ARG — 完整开发文档》制作的单页中文恐怖 ARG。

## 体验方式

直接打开 `index.html`，或在目录中启动任意静态文件服务器。

起始关键词为 `人和医院`。玩家通过档案中的关联词推进调查，最终解锁 `真相`。

## 已实现

- 25 份可搜索档案与关键词别名
- 无显式线索按钮：后续关键词自然藏在档案正文、批注和日期中
- 7 张线索专属恐怖影像、解锁式影像胶卷与全屏看图
- 本地调查进度、档案抽屉和重置功能
- 恐怖等级 1—5 的渐显、闪烁、震动与全屏惊吓反馈
- 默认关闭的环境低频音
- “真相”进度门槛与双结局选择
- 桌面和移动端响应式布局
- 键盘操作：`/` 聚焦搜索，`Esc` 关闭浮层
